How do you build AI agents that are fast, reliable, compute-efficient, and accountable in production?

NUS SoC AI Society is teaming up with Terminal 3 for a technical deep dive into modern agentic systems. We’re skipping the high-level product pitches to break down the systems engineering, runtime constraints, and research ideas that make agents tick under the hood :]

## \[ WHAT WE'LL EXPLORE \]
- Architecture: Multi-agent orchestration and runtime dataflows
- Optimisation: Minimising latency and compute bottlenecks
- Reliability: Enforcing determinism and mitigating failure modes
- Security: Auditable execution trails and enclave security
- Applied Research: Translating cutting-edge papers into code
